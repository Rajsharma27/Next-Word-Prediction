# 🧠 Next Word Prediction

This is a deep learning project to predict the next word in a sentence using LSTM networks. It takes a sequence of words as input and predicts the most probable next word, similar to how autocomplete works in smartphones.

The model is trained on a large English corpus using Keras and TensorFlow. It involves text preprocessing, tokenization, sequence generation, and training an LSTM-based architecture.

The goal of this project is to explore how language models understand context and predict continuations of a sentence.

## 🔧 Features

- Predicts the next word given a text prompt
- Built with LSTM layers
- Uses Tokenizer and padded sequences
- Option to deploy with Flask

## 📊 Example Input/Output

**Input:** `The future of AI is`  
**Prediction:** `bright`

**Input:** `Data science is a`  
**Prediction:** `field`

## 📚 Requirements

- Python 3.7+
- TensorFlow
- NumPy
- Keras
- Flask (optional)
